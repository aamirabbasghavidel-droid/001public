# تحقیق: تنظیم خودکار اسلایسر برای Elegoo Neptune 4 Plus

> مرحله‌ی ۱ پروژه — بررسی پروژه‌های موجود و بهترین تنظیمات برای کیفیت سطح.
> مقادیری که با ⚠️ علامت خورده‌اند از منبع مستقیم تأیید نشده‌اند و باید با پرینت تست چک شوند.

## ۱. پروژه‌های موجود در گیت‌هاب

| دسته | پروژه‌های مهم | چه کار می‌کنند |
|---|---|---|
| اسلایسرها | [OrcaSlicer](https://github.com/OrcaSlicer/OrcaSlicer) (۱۶k⭐)، [PrusaSlicer](https://github.com/prusa3d/PrusaSlicer)، [Cura](https://github.com/Ultimaker/Cura)، [BambuStudio](https://github.com/bambulab/BambuStudio)، [ElegooSlicer](https://github.com/elegooofficial/ElegooSlicer) | ارتفاع لایه‌ی تطبیقی، پرینت‌های کالیبراسیون داخلی (دما، فلو، PA، رتراکشن، حداکثر فلو) — ولی نتیجه را باید خود کاربر با چشم بخواند |
| راهنما و پروفایل | [Ellis Print Tuning Guide](https://github.com/AndrewEllis93/Print-Tuning-Guide)، [Teaching Tech](https://github.com/teachingtechYT/teachingtechYT.github.io)، [OpenNeptune3D/slicer-generator](https://github.com/OpenNeptune3D/slicer-generator) | ترتیب کالیبراسیون، پروفایل‌های ثابت |
| کالیبراسیون خودکار | [klippain-shaketune](https://github.com/Frix-x/klippain-shaketune)، [rubedo](https://github.com/furrysalamander/rubedo)، [PressureAdvanceCamera](https://github.com/undingen/PressureAdvanceCamera) | Input shaper با شتاب‌سنج؛ PA با لیزر/دوربین |
| هوش مصنوعی | [Obico](https://github.com/TheSpaghettiDetective/obico-server)، [caxton](https://github.com/cam-cambridge/caxton)، [slicer-copilot](https://github.com/pfrankov/slicer-copilot) | تشخیص خرابی؛ اصلاح فلو در حین چاپ (تحقیقاتی)؛ LLM که تنظیمات 3MF را عوض می‌کند |
| تحلیل مدل | [Tweaker-3](https://github.com/ChristophSchranz/Tweaker-3) | جهت‌دهی خودکار مدل |
| مخصوص Neptune 4 | [OpenNept4une](https://github.com/OpenNeptune3D/OpenNept4une) (۶۸۵⭐) | Klipper/Moonraker اصلی + KAMP + شتاب‌سنج |

**خلأ موجود:** هیچ ابزاری از «مدل + پرینتر + فیلامنت + هدف» یک پروفایل کامل و معتبر نمی‌سازد و از نتیجه‌ی پرینت‌های قبلی یاد نمی‌گیرد.

### چطور برنامه اسلایسر را کنترل کند
- ElegooSlicer فورکِ OrcaSlicer است؛ پروفایل‌های Neptune 4 Plus عیناً در OrcaSlicer هم هست.
- CLI تأییدشده‌ی OrcaSlicer:
  ```
  orca-slicer --datadir DIR --load-settings "machine.json;process.json" \
    --load-filaments "filament.json" --slice 0 --outputdir OUT model.stl
  ```
- پروفایل‌ها JSON با زنجیره‌ی `inherits` هستند؛ مقدارها رشته‌اند (`"nozzle_temperature": ["210"]`). برنامه باید زنجیره را کامل باز کند و تغییرات خودش را رویش بنویسد.
- ارسال به پرینتر: Moonraker روی پورت 7125 — `POST /server/files/upload` با `print=true`.

## ۲. مشخصات Neptune 4 Plus (برای محاسبه)

| مورد | مقدار |
|---|---|
| حداکثر دمای نازل | 300 °C |
| حداکثر دمای بستر | 100–110 °C (منابع اختلاف دارند → حداکثر 100 در نظر بگیر) |
| شتاب در پروفایل | XY = 8000، Z = 300 |
| گام کامل محور Z | 8 / 200 = **0.04 mm** → ارتفاع لایه مضرب 0.04 باشد |
| محدوده‌ی ارتفاع لایه | 0.08–0.28 mm |
| حداکثر فلو (پروفایل) | PLA = 16 (PLA Basic = 21)، ASA = 12 mm³/s |

**مشکل پروفایل پیش‌فرض برای کیفیت سطح:** دیواره‌ی بیرونی 160 mm/s (≈75% حداکثر فلو) با فقط ۲ دیواره و بدون scarf seam → موج (ringing) و سطح مات.

## ۳. فرمول‌هایی که نرم‌افزار باید استفاده کند

| پارامتر | فرمول |
|---|---|
| ارتفاع لایه | `h = snap(h, 0.04)`، محدود به `[0.2·d, 0.75·d]` |
| ارتفاع لایه‌ی تطبیقی | `h = clamp(c_max / |n_z|, h_min, h_max)` (مدل cusp) |
| عرض خط | بیرونی 1.05·d، داخلی 1.125·d، رویی 1.0·d |
| سقف سرعت | `v = k·Q_max / ((w−h)·h + π·h²/4)` — k = 0.5–0.6 برای دیواره‌ی بیرونی، 0.85 برای داخلی |
| شتاب دیواره‌ی بیرونی | 0.3 / 0.5 / 0.7 × max_accel پیشنهادی input shaper (محور Y) |
| تعداد لایه‌ی رویی | `ceil(T / h)` با T = 0.8–1.0 mm |
| Overhang | `overhang% = h·tanθ / w` |
| جبران انقباض | `scale = 100 / (100 − s%)` |

## ۵. ASA روی پرینتر بدون محفظه

- **محفظه:** برای قطعه‌های بزرگ‌تر از ~100mm یا بلند تقریباً ضروری است (چادر/جعبه‌ی DIY). بدون آن: **Draft shield** تمام‌ارتفاع، حداقل ۲ دور + brim.
- **چسبندگی:** PEI بافت‌دار + چسب ماتیکی PVA، brim پنج تا هشت میلی‌متر، elephant foot 0.1–0.15، قطعه را وسط بستر بگذار و بستر را ۱۰–۱۵ دقیقه پیش‌گرم کن.
- **فیلامنت خشک** و دور از کولر/باد.
- **ایمنی:** ASA ذرات ریز و استایرن منتشر می‌کند — در اتاق خواب یا اتاق بسته چاپ نکن؛ تهویه به بیرون یا فیلتر HEPA + کربن.

## ۶. ترتیب کالیبراسیون

1. مکانیک (تسمه‌ها، Z) → 2. برج دما → 3. فلوی تقریبی → 4. Pressure Advance → 5. فلوی دقیق → 6. رتراکشن → 7. حداکثر فلوی حجمی → 8. Input shaper / برج شتاب → 9. برج VFA (پیدا کردن سرعت‌های بد برای دیواره‌ی بیرونی)

## ۷. جدول عیب‌یابی سطح

| عیب | علت | تنظیم |
|---|---|---|
| خطوط لایه / پله‌ای | لایه‌ی ضخیم | لایه‌ی نازک‌تر یا تطبیقی |
| نوارهای منظم (Z-banding) | لایه مضرب 0.04 نیست | snap به 0.04 |
| موج کنار گوشه‌ها (ringing) | شتاب زیاد | input shaper، شتاب بیرونی کمتر |
| خط‌های ریز عمودی (VFA) | موتور/تسمه | تغییر سرعت دیواره‌ی بیرونی |
| دانه/حباب روی seam | PA تنظیم نیست | PA، wipe، scarf seam |
| گوشه‌های برآمده | PA کم | افزایش PA |
| سطح مات | سرعت بیش از ظرفیت ذوب | سرعت کمتر یا دمای بیشتر |
| سوراخ روی سطح رویی | لایه‌ی رویی کم | ضخامت رویی ≥ 0.8mm |
| رویه‌ی موج‌دار | over-extrusion | کاهش فلو، ironing |
| تار عنکبوتی | دمای زیاد/رتراکشن کم | دمای کمتر، تنظیم رتراکشن |
| ترک بین لایه‌ها (ASA) | سرد شدن سریع | محفظه/draft shield، فن کمتر |
